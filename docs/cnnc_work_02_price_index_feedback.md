# 中核核心工作事项 02：价格指数勘误和运营反馈问题处理

> 适用范围：中核商城标准商品价格库 / 运营群反馈 / 工单反馈 / 客户补充链接 / 价格指数异常处理  
> 工作频率：每日工作，一般日清  
> 处理目标：对客户或运营反馈的价格异常、同款问题、补充链接、重新采集需求进行核查、处理和反馈  
> Agent 定位：提供问题归因、流程指引、数据检查建议；不得自动导入、自动解绑、自动推送、自动改库。

---

## 1. 工作事项定义

本事项对应中核 8 项核心工作中的第 2 项：

**中核商城价格指数勘误和运营反馈问题处理。**

客户或运营人员每日可能通过运营群、工单、邮件等方式反馈：

- 价格指数异常；
- 价格偏高或偏低；
- 标准商品需要重新提供同款链接；
- 原有同款不准；
- 需要驳回数据；
- 需要加急生成价格指数；
- 某些商品需要重新采集或重新推送。

该类问题通常要求当天处理、当天反馈。

---

## 2. 输入信息与识别字段

### 2.1 常见输入

客户或运营可能提供：

- 标准商品编码；
- 潜在变异编码；
- 标准商品名称；
- 供应商推品名称；
- 客户确认的正确链接；
- 错误链接说明；
- 参考价或期望价格；
- 价格异常描述；
- 加急标记。

### 2.2 关键编码转换

处理中需要注意：

```text
客户给的标准商品编码 / 潜在变异编码
↓
需要转换为 SAAS 系统中的监控商品编码 / Document ID
↓
再用于同款导入、重新计算、推送等流程
```

不得直接混用商城编码和 SAAS 编码。

---

## 3. 标准处理流程

### Step 1：接收反馈并识别问题类型

常见问题类型：

| 反馈类型 | 识别关键词 | 初步判断 |
|---|---|---|
| 价格异常 | 价格不对、价格偏高、价格偏低、指数异常 | 核查同款价格、页面价、指数计算 |
| 补充链接 | 重新提供链接、正确链接、参考链接 | 需要校验链接并补入系统 |
| 重新采集 | 重新采、采集不到、同款不足 | 核查采集状态或手动触发采集 |
| 驳回请求 | 需要驳回、处理失败、校验失败 | 核查是否无同款或只有一条同款 |
| 加急需求 | 加急、尽快、今天要处理 | 优先处理客户提供链接或最新采集结果 |

### Step 2：根据标准商品编码查询价格库

在中核商城标准商品价格库中，根据客户提供的编码查询对应标准商品。

优先使用：

1. 标准商品编码；
2. 潜在变异编码；
3. 标准商品名称；
4. 供应商推品名称。

查询目标：

- 确认商品是否存在；
- 确认当前状态；
- 查看价格指数；
- 查看同款信息；
- 查看历史推送记录；
- 判断是否为已生效商品或相关待处理状态。

### Step 3：找到 SAAS 对应监控商品编码 / Document ID

如果需要在 SAAS 系统导入同款或重新计算价格指数，必须先取得 SAAS 对应编码。

来源：

- SAAS 页面查询；
- 批量工具查询；
- 后台导出的编码对应关系；
- 必要时请相关同事从后台数据库导出对应关系表。

常用字段包括：

| 字段 | 用途 |
|---|---|
| Document ID | SAAS 中用于定位商品的 ID |
| 标准商品编码 | 商城标准商品标识 |
| 潜在变异编码 | 商城侧另一类商品标识 |
| 供应商推品名称 | 供应商提交的商品名称 |
| 推荐标准商品名称 | 商城生成或推荐的标准名称 |

### Step 4：校验客户提供的链接

客户提供的链接不能直接无条件使用，仍需核验：

- 链接是否能打开；
- 商品是否上架；
- 是否与标准商品为同款；
- 页面价格是否与客户描述一致；
- 多条链接是否来自不同商城；
- 多条链接之间价差是否合理；
- 是否存在一条正确、一条错误的情况。

### Step 5：判断是否需要补录同款

以下情况可考虑补录客户提供同款：

| 情况 | 处理 |
|---|---|
| 系统未采集到足够同款，但客户提供了 2 条以上不同商城有效同款 | 可补录后重新计算 |
| 系统原同款错误，客户提供正确链接 | 可解绑错误同款，保留或补录正确同款 |
| 系统采集价格过期或页面价不一致 | 应驳回旧数据或重新采集 |
| 客户提供链接价差过大 | 不建议直接补录，应反馈客户确认 |
| 客户只提供 1 条有效链接 | 不足以生成指数，需继续补同款 |

### Step 6：使用固定模板导入 SAAS

补录同款时，需使用固定导入模板。

模板字段通常包括：

- 标准商品编码；
- 潜在变异编码；
- SAAS 监控商品编码 / Document ID；
- 商品名称；
- 供应商推品名称；
- 推荐标准商品名称；
- 同款信息；
- SKV / SKU；
- 商场名称；
- 链接；
- 价格；
- 评论数。

导入前必须完成编码转换：

```text
标准商品编码 / 潜在变异编码
→ SAAS 监控商品编码 / Document ID
```

### Step 7：处理原有错误同款

如果客户反馈的价格异常是由于原有同款错误导致：

1. 查看当前已绑定同款；
2. 判断哪些是错误同款；
3. 对错误同款进行人工解绑；
4. 保留客户确认正确的同款；
5. 重新计算价格指数；
6. 推送更新结果。

注意：

- 解绑、导入、重算、推送均为人工操作；
- Agent 不能自动执行。

### Step 8：重新计算并推送价格指数

当正确同款满足条件后：

1. 在 SAAS 中重新计算价格指数；
2. 检查价格指数是否合理；
3. 检查同款数量是否至少 2 条不同商城；
4. 检查价格差异是否过大；
5. 人工点击推送；
6. 推送后在商城侧确认状态和价格指数是否更新。

## 4. 典型问题处理规则

### 4.1 价格指数偏高

可能原因：

- 高价离群同款参与计算；
- 低价合理同款被去极值逻辑剔除；
- 原有错误同款未解绑；
- 客户提供低价链接未补入；
- 页面价格已更新但 ES 历史价格未更新。

建议：

1. 查看参与价格指数计算的同款；
2. 对比同款页面实际价格；
3. 检查是否同一商城多链接重复；
4. 判断是否存在异常高价；
5. 必要时人工解绑错误同款并补录正确同款；
6. 重新计算并推送。

### 4.2 价格指数偏低

可能原因：

- 异常低价链接参与计算；
- 商品规格不一致；
- 链接跳转或错误商品；
- 页面价格与采集价格不一致；
- 客户提供链接本身有误。

建议：

1. 打开低价链接核查商品是否同款；
2. 核查规格型号是否一致；
3. 核查页面实际价格；
4. 错误链接不参与计算；
5. 如价差过大，应反馈客户重新确认。

### 4.3 价格指数生成失败

常见原因：

- 没有同款；
- 只有 1 条同款；
- 只有同一商城的重复链接；
- 爬虫未采集完成；
- 部分商城无法访问；
- 同款仍处于匹配中。

处理：

1. 判断是否还在采集匹配中；
2. 若当天仍在流程中，可等待；
3. 若次日仍无数据，排查爬虫或采集链路；
4. 如客户提供有效补充链接，可按模板补录；
5. 满足 2 条不同商城同款后重新计算并推送。

### 4.4 客户要求驳回

客户或运营要求驳回时，需确认原因。

可驳回场景：

- 无同款；
- 只有一条同款；
- 链接错误；
- 链接失效；
- 同款不匹配；
- 价格严重异常；
- 客户确认当前数据不应生效。

处理方式：

```text
人工解绑异常同款
↓
人工点击立即推送
↓
使其进入校验失败状态
```

注意：

- 不得跳过审批流程；
- 应保留采集与处理留痕；
- Agent 不得自动解绑或自动推送。

### 4.5 加急处理

客户加急时：

1. 优先查看客户是否提供链接；
2. 如果提供链接，优先校验其有效性和同款关系；
3. 如果未提供链接，优先查看系统最新采集结果；
4. 如果仍无数据，可考虑人工介入 SAAS 采集；
5. 处理完成后及时反馈。

## 5. 班车数据与每日反馈的关系

每日反馈通常是运营群或工单中的临时问题，要求当天处理。

若校验失败商品后续需要上架，客户或供应商可能通过每周三班车数据提供同款链接。班车数据属于后续每周工作事项，但与本事项存在衔接关系：

```text
每日问题反馈
→ 判断无法生成价格指数
→ 进入校验失败
→ 客户/供应商通过班车补充同款
→ 补录同款
→ 重新计算
→ 推送成功
```

## 6. 数据质量控制规则

### 6.1 不能完全接受客户链接

客户提供的链接通常可信，但仍需核查：

- 是否同款；
- 是否不同商城；
- 是否有效；
- 是否价格合理；
- 是否页面价格一致。

### 6.2 保留采集流程留痕

即使客户提供了两条链接，也不建议完全绕过采集流程。

原因：

- 后续可能需要提供原始采集数据；
- 审计可能要求查看采集、过滤、审批全过程；
- 直接使用客户链接而无采集留痕，后续难以解释。

### 6.3 价差过大应反馈客户

如客户提供多个链接但价格差异过大，应反馈客户重新确认，而不是直接推送。

### 6.4 只保留正确链接

如果客户提供的链接中一条正确、一条错误：

- 正确链接可参与计算；
- 错误链接不参与计算；
- 若有效链接不足 2 条，则不能生成价格指数。

## 8. Agent 禁止自动执行的操作

Agent 只能提供诊断和建议，不得自动执行：

- 自动导入客户链接；
- 自动解绑错误同款；
- 自动点击立即推送；
- 自动重算价格指数；
- 自动修改价格指数；
- 自动审批或驳回；
- 自动写库；
- 自动生成写库 SQL；
- 自动重推任务。

涉及以上动作时，只能输出：

```text
建议人工在 SAAS / 中核商城系统中核查后处理。
```
