# GLM-5.3 本地磁盘安全门禁（CNNC 验收数据回溯）

> 本文件优先级高于验收回溯任务中的“递归扫描本地历史目录”等泛化描述。
> 目标：允许读取历史真实数据，但绝不允许因为全盘扫描、复制、解压、缓存、临时文件或重复导出把 E 盘写满。

## 0. 总原则

本任务是 **READ-MOSTLY / WRITE-BOUNDED** 数据整理任务。

- 历史数据目录只读。
- 禁止扫描整个 `E:\` 根目录。
- 禁止把历史源文件复制到工作目录。
- 禁止为了分析批量解压归档、复制工作簿、生成同尺寸中间文件。
- 禁止创建无限增长的缓存、日志、SQLite/DuckDB 临时库、parquet 镜像、CSV 镜像。
- 禁止任何“先全部转格式再处理”的做法。
- 最终只允许写入一个专用输出目录。
- 任何时候如果无法证明写盘规模受控，立即停止并报告，不要继续试。

## 1. 允许读取的目录

不得从 `E:\` 根开始递归遍历。

默认只允许在明确的 CNNC 工作目录中读取，例如：

```text
E:\.A中核运维\
```

但扫描必须采用 **分阶段、受限目录、只读** 方式：

1. 先读取目录树/文件元数据；
2. 只筛选与中核历史数据相关的文件；
3. 再按需打开命中的文件；
4. 不允许把所有文件全文加载或复制一遍。

明确排除以下高风险/无关目录（如存在）：

```text
.git\
node_modules\
.venv\
venv\
__pycache__\
.cache\
.tmp\
temp\
logs\  （除非明确需要某个小日志作证据）
runtime\ 下与本任务无关的大型重复产物
浏览器缓存
模型缓存
系统目录
```

如果需要扩大读取范围，必须先停止并报告拟新增目录，不得自行把范围扩大到整个盘符。

## 2. 写入目录唯一化

所有新生成文件只能写到一个专用目录，例如：

```text
E:\.A中核运维\_acceptance_reconstruction_20260911\
```

禁止在以下位置创建临时/输出文件：

```text
E:\ 根目录
历史源数据目录旁边
多个日期目录散落写入
每个源文件旁生成副本
```

输出目录建议结构：

```text
_acceptance_reconstruction_20260911\
  output\              # 最终 5 个客户 xlsx
  internal\            # 小型内部审计/血缘报告
  logs\                # 单个受控日志
```

不得为每个历史源文件创建副本或转换产物。

## 3. 开始前必须执行磁盘预检

开始任何大文件写入前，记录：

```text
E 盘总容量
E 盘已用空间
E 盘可用空间
工作目录当前大小
```

硬门禁：

- 如果 E 盘可用空间 `< 20 GB`：停止，不执行大规模处理；
- 处理中如果 E 盘可用空间 `< 15 GB`：立即停止后续写入；
- 不得通过删除用户历史文件来腾空间；
- 不得自动清理用户目录、回收站或其他任务产物。

只能清理 **本任务自己本轮新建的临时文件**，且必须明确知道文件路径属于本任务专用目录。

## 4. 本任务写盘预算

默认总新增写盘预算：

```text
5 GB HARD CAP
```

包括：

- 5 个最终 XLSX；
- 内部 lineage / audit 文件；
- 日志；
- 本任务自己创建的临时文件。

如果预测会超过 5 GB：

```text
STOP_DISK_BUDGET_EXCEEDED
```

停止并报告预计规模，不得继续生成。

正常情况下，本任务不应接近 5 GB。

## 5. 禁止的大型中间产物

严禁以下做法：

1. 把所有历史 Excel 转成 CSV；
2. 把所有历史 Excel 转成 parquet；
3. 把所有历史数据合并成一个全量镜像文件后再分析；
4. 为每个源文件生成清洗版副本；
5. 批量解压 ZIP/RAR 到磁盘；
6. 创建与全部源文件总体积相当的 SQLite/DuckDB 数据库；
7. 创建不设上限的 pandas pickle/joblib/cache；
8. 日志打印完整行数据导致日志无限增长；
9. 保存每一步全部 debug dataframe；
10. 重复生成 `_v1/_v2/_v3/final/final2` 大文件。

## 6. 正确的大文件处理方式

优先：

- 先读 workbook 元数据、sheet 名、表头；
- 先按 `标准商品编码` 集合过滤；
- 使用 openpyxl `read_only=True` / 流式方式读取大型 xlsx；
- CSV 使用 chunksize；
- JSON 使用逐行/流式解析；
- 只保留任务需要的列；
- 候选在内存中按键去重，必要时采用小型受控索引；
- 一次处理一个文件或一个批次；
- 处理完立即释放对象；
- 不将完整源文件重新序列化到磁盘。

如果使用临时索引数据库：

- 必须位于本任务专用目录；
- 必须设置大小监控；
- 预计超过 2 GB 时停止，重新设计为流式处理；
- 完成后只删除该专用临时库，不碰其他文件。

## 7. 目录扫描也要受控

第一次只做 **metadata inventory**，禁止边扫描边转换文件。

第一轮只输出小型清单：

```text
path
size
mtime
extension
可能用途
是否需要二次打开
```

优先搜索文件名/路径包含：

```text
中核
同款
价格指数
去极值
去重
一物多码
评论
审核
交付
召回
互联网
```

再根据 120,047 标准商品编码做定向读取。

不要为了“提高召回”无差别读取整个 E 盘所有 Excel。

## 8. 日志上限

日志必须摘要化：

- 不打印每一行记录；
- 每个源文件只记录统计；
- 错误样例最多保留有限条；
- 单个日志超过 100 MB 立即停止详细日志，切换摘要模式；
- 禁止生成 GB 级日志。

## 9. Excel 输出策略

最终只生成一次正式版：

```text
01_同款校验结果数据.xlsx
02_去极值后结果数据.xlsx
03_一物多码去重后结果数据.xlsx
04_人工审核通过结果数据.xlsx
05_价格指数计算结果数据.xlsx
```

生成前先在内存/小型统计中完成门禁检查。

不要反复写：

```text
01_v1.xlsx
01_v2.xlsx
01_final.xlsx
01_final2.xlsx
```

如需测试写入，最多使用非常小的抽样文件，并在正式生成前删除本任务自己的抽样产物。

## 10. 删除权限边界

本任务禁止：

- 删除任何历史源文件；
- 删除任何非本任务创建文件；
- 清空目录；
- `rmdir /s`、`Remove-Item -Recurse` 指向非专用工作目录；
- 磁盘清理；
- 自动删除旧项目/runtime；
- 修改、移动、重命名历史验收文件。

允许删除的只有：

```text
本轮任务专用目录中，由本轮程序明确创建的临时文件
```

并且删除前必须验证绝对路径位于 `_acceptance_reconstruction_20260911` 下。

## 11. 每个阶段必须报告磁盘状态

至少在以下节点报告：

```text
PRECHECK
历史文件 inventory 完成
Step1 完成
Step2 完成
Step3 完成
Step4 完成
Step5 完成
FINAL
```

每次报告：

```text
E_FREE_GB
WORKDIR_SIZE_GB
NEW_BYTES_WRITTEN_GB
```

出现异常增长立即停止。

## 12. Fail Closed

出现以下任一情况直接停止：

```text
无法确定某命令会写多少数据
临时目录开始异常膨胀
可用空间低于门限
发现代码正在复制所有源文件
发现程序开始全盘递归 E:\
发现程序要批量转换全部历史文件
发现工作目录预计超过 5 GB
```

输出：

```text
DISK_SAFETY_STOP
原因：...
当前 E_FREE_GB：...
当前 WORKDIR_SIZE_GB：...
下一步建议：...
```

禁止“先跑完再清理”。
