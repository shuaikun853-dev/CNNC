### Status interpretation from live evidence

- `task_status='00' AND queue_status='00' AND enqueue_time IS NULL`: generated in central control but not yet enqueued.
- `task_status='00' AND queue_status='01' AND enqueue_time IS NOT NULL`: enqueued but not yet running/completed.
- `task_status='01' AND queue_status='02'`: executing / in processing path.
- `task_status='02' AND queue_status='02'`: completed.
- `task_status='03' AND queue_status='02'`: failed/abnormal terminal state observed.

Important correction: `start_time` is NOT reliable evidence that execution actually started. Live `00/00` rows have `start_time` populated. Use `enqueue_time`, `task_status`, and `queue_status` instead.

## Key diagnostic query — node-wide state by mall

```sql
SELECT
    mall,
    task_status,
    queue_status,
    COUNT(*) AS 任务数,
    SUM(enqueue_time IS NULL) AS 未产生入队时间,
    SUM(enqueue_time IS NOT NULL) AS 已产生入队时间,
    MIN(create_time) AS 最早创建,
    MAX(create_time) AS 最晚创建,
    MAX(enqueue_time) AS 最后入队时间,
    MAX(update_time) AS 最后更新时间
FROM central_control_sub_demo.s_task_info
WHERE node_id = 10000000003
  AND is_valid = '1'
  AND create_time >= '2026-08-26 19:00:00'
GROUP BY mall, task_status, queue_status
ORDER BY mall, task_status, queue_status;
```
