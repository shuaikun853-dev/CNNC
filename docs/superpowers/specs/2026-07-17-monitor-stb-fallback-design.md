# 监控表招商局与史泰博处理设计

## 目标

为第三步固定入口增加两个显式运行参数：从 `data/ZHAOSHANG_DB.env` 在进程内加载招商局优先级数据库变量，以及在招商局阶段结束后仅对仍缺价的 `stbchina.cn` 链接运行史泰博专用脚本并回填结果。

## 边界

- 密码、账号、Cookie、Token 均不得写入 Markdown、日志、Excel 或代码。
- `ZHAOSHANG_DB.env` 只在运行时读取并注入当前进程及招商局子进程；默认不读取。
- 史泰博兜底默认关闭，必须显式传入 `--auto-stbchina-fallback`。仅处理本次已进入模板、招商局后仍无有效价格的 `stbchina.cn` URL。
- 招商局仍先于任何本地爬虫运行。非史泰博商城继续产出待确认清单，不自动执行脚本。
- 遇到 403、405、验证码、登录限制或脚本失败时停止史泰博阶段，保留招商局阶段结果和明确失败记录。

## 实现

固定入口新增 `--zhaoshang-db-env` 与 `--auto-stbchina-fallback` 参数。前者校验四个变量名并加载，后者在招商局回填后的缺价集合中筛选史泰博链接，调用外部 `stbchina_fast_crawler.py`，再按 URL 精确回填价格、标题、uid 和评论数。

输出保留招商局阶段三文件和待确认清单；发生史泰博回填时，另存 `导入zhimport模版_<批次>_招商局_STB补价后.xlsx` 与 `STB补价后仍无价格清单_<批次>.xlsx`，不覆盖招商局阶段文件。

## 验证

新增单元测试覆盖 env 文件的格式校验、史泰博 URL 筛选和结果按 URL 回填。运行脚本语法检查及相关测试。实际批次运行前验证四个变量存在但不输出其值；运行后检查生成文件、行数和缺价清单。
